# Shelf Life Scanner

Scans GS1 DataMatrix and regular barcodes, reads expiry/batch/serial, and calculates remaining shelf life.

Live: https://drw-21.github.io/gs1drw/

# CPD Pocket

Log CPD in seconds, keep certificates with each activity, and see whether you're on track for renewal.
Tracks credential expiry (licence, BLS, indemnity), exports CSV and a printable PDF record, and backs up to a file.
Everything is stored in the browser — no account.

Live: https://drw-21.github.io/gs1drw/cpdpocket/
